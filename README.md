# ساخت فایل ویندوز (exe) انبار یار
1. این پوشه را در یک Repository گیت‌هاب (شاخه main) آپلود کنید.
2. تب Actions › Build Windows EXE › Run workflow.
3. بعد از حدود ۱۰ دقیقه، فایل anbar-yar-windows را دانلود کنید. داخلش فایل exe قابل اجرا است و نیازی به نصب ندارد.

برای اجرای آزمایشی روی کامپیوتر خودتان (اختیاری): Node.js را نصب کنید، در این پوشه `npm install` و سپس `npm start` بزنید.
